天秤将棋（[ルール](https://tenbinshogi.com/rules/)）の AI「Libra」の 2 番目の公開版。
**自己対局だけ**で学習しており、既存の将棋 AI のコード・評価関数・重み・棋譜・評価値を内部にも学習信号にも使っていません。

- 重み: 本体 run `ls` の **step 317,975**（2026-09-21 17:22:02 到達、自己対局 3,600,108 局）
- ネット: Transformer エンコーダ、`d_model` 320 / 8 層 / 8 ヘッド、**10,233,090 パラメータ**（v0.1 から変えていません）
- ルールの版: [docs/rules.md](https://github.com/kotenbu135/LibraShogi/blob/v0.2/docs/rules.md)（二飛香を含む）
- **[モデルカード](https://github.com/kotenbu135/LibraShogi/blob/main/docs/model-card-v0.2.md)** に、学習の設定・計測・**既知の限界 7 点**をまとめています

## v0.1 からどれだけ強くなったか

**直接対局 1,000 局で +300.0 Elo**（95% 区間 +271.6〜+332.1、得点 0.849）。Elo の差 +300 は勝率にして約 85% です。

| | 勝 | 敗 | 分 |
|---|---|---|---|
| v0.2 が先手 | 485 | 0 | 0 |
| v0.2 が後手 | 364 | 151 | 0 |

条件は両者とも読み 96 回・根の Gumbel ノイズあり・玉は一様乱数、平均 77.0 手。引き分けは 0 局。

**v0.2 は v0.1 の続きではありません。** リプレイ（学習に使う最近の対局の範囲）の設定の誤りが分かったため、
2026-09-18 にゼロから学習し直した別系列です（モデルカード §3）。

玉配置表（`scale-v0.2.json`）も v0.2 のネットから作り直し、**全 492 組を 196,328 局で検証**しました。
表の見込みと実際の勝率の差は **−0.0003（標準誤差 0.0026）で 0 と見分けが付きません**（v0.1 は −0.008）。

## 使い方（Windows）

zip を展開し、天秤将棋対応の GUI（[tenbin-shogi-desktop](https://github.com/kotenbu135/tenbin-shogi-desktop) 0.10.0 以降）に `libra.exe` を登録します。
布石と本将棋の両方に選べば、1 手目から終局まで指します。

**v0.1 から変わった点が 2 つあります。**

- **`Scale_Table` の設定が要らなくなりました。** 指定しなければ `libra.exe` の隣の `scale.json` を自動で読みます
  （v0.1 では既定が空で、手で場所を入れる必要がありました）。モデル（`DNN_Model`）も従来どおり隣の `libra.onnx` を読みます。
- **エンジンを登録し直してください。** 名乗りが `LibraShogi 0.0.2` から `LibraShogi 0.2.0` に変わっています。

## 強さについて

**外部エンジンに対する強さは測れていません。** 自動の外部計測が 320 万局・360 万局の節目で失敗しており、
記録が 1 局も残っていません（モデルカード §5.6。原因は調査中）。上の +300 Elo は**自分の過去の版が相手**の値です。

そのほか残っている穴（モデルカード §6）:

- **搾取者（本体の弱点ばかり探す小さいネット）に対する穴は未計測。** v0.1 では 86〜90% 負けていましたが、
  今の系列では搾取者を回していないため、この穴が残っているかどうかは分かりません。
- **本将棋（41 手目以降）の読み抜けは未確認。** 自己対局では本将棋の局面で探索値が結果より 0.054 低く出ています。
- **持ち時間などを揃えた条件での絶対的な強さは未計測。** これは 1.0 で測ります。
- ルールの版は二飛香を含む今の [rules.md](https://github.com/kotenbu135/LibraShogi/blob/v0.2/docs/rules.md) 固定で、
  それより前の棋譜は読めません。
