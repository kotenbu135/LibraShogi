天秤将棋（[ルール](https://tenbinshogi.com/rules/)）の AI「Libra」の 3 番目の公開版。
**自己対局だけ**で学習しており、既存の将棋 AI のコード・評価関数・重み・棋譜・評価値を内部にも学習信号にも使っていません。

- 重み: 本体 run `ls` の **step 812,226**（2026-10-04 06:55 JST 到達、自己対局 10,000,000 局）。v0.2（360 万局）と同じ系列の続きです
- ネット: Transformer エンコーダ、`d_model` 320 / 8 層 / 8 ヘッド、**10,233,090 パラメータ**（v0.1 から変えていません）
- ルールの版: [docs/rules.md](https://github.com/kotenbu135/LibraShogi/blob/v0.3/docs/rules.md)（二飛香を含む）
- **[モデルカード](https://github.com/kotenbu135/LibraShogi/blob/main/docs/model-card-v0.3.md)** に、学習の設定・計測・**既知の限界 8 点**をまとめています

## v0.2 からどれだけ強くなったか

**直接対局 1,000 局で +147.6 Elo**（95% 区間 +124.7〜+171.8、得点 0.7005）。Elo の差 +150 は勝率にして約 70% です。

| | 勝 | 敗 | 分 |
|---|---|---|---|
| v0.3 が先手 | 412 | 87 | 1 |
| v0.3 が後手 | 288 | 212 | 0 |

条件は両者とも読み 96 回・根の Gumbel ノイズあり・玉は一様乱数、平均 91.3 手。

v0.2 から学習に足したもの:

- **重みの平均（EMA）。** 学習中の重みを一定の間隔で平均した重みで指します（比べの試験でそのままの重みより +51.1 Elo）
- **自己対局の投了。** 勝ち目がほぼ無くなった局を早めに終えて、1 日に打てる対局を増やしました
- **後手玉を四段目に置く割合を 25% から 5% に。** 41 手目の裁定でほぼ決まってしまう局を減らしました

## 変わった点（使う人向け）

- **玉配置表（`scale.json`）を配るのをやめました。** 1〜2 手目の両玉は `libra.exe` が読んで置きます
  （先手玉は乱数、後手玉は先手の勝率が五分にいちばん近いマス）。zip にも `scale.json` は入っていません。

## 使い方（Windows）

zip を展開し、天秤将棋対応の GUI（[tenbin-shogi-desktop](https://github.com/kotenbu135/tenbin-shogi-desktop) 0.10.0 以降）に `libra.exe` を登録します。
布石と本将棋の両方に選べば、1 手目から終局まで指します。登録時に入れる設定はありません（モデルは隣の `libra.onnx` を自動で読みます）。

## 強さについて

**外部エンジンに対する強さは測っていません。** 外部計測は 2026-09-28 から止めています（モデルカード §5.7）。上の +147.6 Elo は**自分の過去の版が相手**の値です。

そのほか残っている穴（モデルカード §6）:

- **920 万局の重みより強いとは言い切れません。** これまで最も強かった自分（920 万局）との 2,000 局は +13.0 Elo（区間 −2.2〜+28.3）で、とくに布石（1〜40 手目）だけを比べると 2 回続けて負けています。
- **搾取者（本体の弱点ばかり探す小さいネット）に対する穴は未計測。** 搾取者は回しましたが、本番の強さの本体と打つ段階まで進まないまま止めました。
- **本将棋（41 手目以降）の読み抜けは未確認。** 自己対局では本将棋の局面で探索値が結果より 0.072 低く出ています。
- **持ち時間などを揃えた条件での絶対的な強さは未計測。** これは 1.0 で測ります。
